# clients/ — client evidence

One folder per account, named by slug (`acme-corp`). Copy `_TEMPLATE/` to start one.

| File | What |
|---|---|
| `record.md` | Status, contacts, gates, what was sent and when, open items |
| `intelligence.md` | Their words: pain, objections, the moment it turned. Reused in copy |
| `custom-offer.md` | Only for a negotiated deal. The one place a figure may depart from canon |
| `calls/` | Transcripts or notes, `YYYY-MM-DD-<type>.md` |
| `outreach/` | Emails and messages **verbatim as sent** |

These are records. When one turns out to be wrong, annotate it with a dated note; do not
rewrite history. A price is cited from `commercial.md`, never stated, except `[contracted]`
lines and `custom-offer.md`.

Cross-client patterns go in `clients/_intelligence.md`.
